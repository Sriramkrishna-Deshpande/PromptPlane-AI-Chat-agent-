# PromptPlane – AI Chat Agent

**PromptPlane** is a lightweight and modern chatbot UI powered by [Gradio](https://gradio.app/) and [Groq’s LLaMA 3.3-70B model](https://groq.com/). This AI agent provides conversational capabilities using LangChain and Groq's high-performance inference backend.

## Features

- Clean chat UI with inline message input and Send button
- Powered by LLaMA 3.3-70B via Groq API
- Stylish orange "Send" button
- Shareable Gradio web interface (with `share=True`)
- Built with Python, Gradio, LangChain, and LangChain-Groq
