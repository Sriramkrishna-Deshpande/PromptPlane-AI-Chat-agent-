# PromptPlane-AI-Chat-agent-
PromptPlane is an AI-powered chat agent using Groq LLM and LLaMA 3. It offers contextual, memory-based interactions with a sleek, customizable interface. Built with Gradio, it provides a seamless and responsive chatbot experience for real-time conversations.
## Features

- **AI-powered Conversations**: Powered by Groq LLM and LLaMA 3 for intelligent and context-aware replies.
- **Memory-based Interaction**: Stores and recalls previous conversation context for better interaction.
- **Customizable UI**: Sleek and minimalistic design using Gradio, optimized for chat-based interactions.
- **Clear Chat Functionality**: Clear the chat history with a single button click.

---

## Technologies Used

- **Groq LLM** for AI-based language models.
- **LLaMA 3** for state-of-the-art large language models.
- **Gradio** for building interactive UIs quickly.
- **Langchain** for managing prompts and conversation flow.

## How to Run

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/PromptPlane.git
    cd PromptPlane
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Replace the `groq_api_key` in the script with your own API key.

4. Run the app:
    ```bash
    python app.py
    ```

5. The chat application will be hosted locally or you can share it with the `share=True` option.

---

## Usage

1. **Input**: Type any query into the message box.
2. **Send**: Hit the "Send" button (styled like an up arrow) to submit the query.
3. **Clear**: Use the "Clear" button to reset the conversation history.
